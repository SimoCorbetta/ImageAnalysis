Image Analysis with application to Microscopy
Projects done during my Erasmus studio semester at Leiden University, in particular while following the Image Analysis Course given by Prof. Fons Verbeek.
We used as python library for image analysis DipLib, a library developed at Leiden University and TU Delft for Image analysis.

The project 5 was about quantification of gene expression in Arabidopsis thaliana embryos starting from imaging data and classify the embryos based on their gene expression.
The project 4 was about to analyze time series images, in particular two different sets of time serie images containing cells treated with a growth factor and the other with a saline solution.The goal was to evaluate eventual difference between the two groups concerning shape, speed and movement of the cells.
